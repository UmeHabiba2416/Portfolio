## ✨ Features of this Website

This portfolio is built using pure HTML, CSS, and Vanilla JavaScript with a custom dark-mode aesthetic. 

* **🎨 Modern UI/UX:** A sleek "Rich Black & Gold" color palette (`#1a1a1a` and `#d4af37`).
* **🖱️ Custom Cursor:** Interactive dual-ring custom cursor tracking.
* **📊 Scroll Progress Bar:** Top-fixed animated indicator of scroll depth.
* **🚀 Scroll Reveal Animations:** Elements smoothly fade and slide in as they enter the viewport.
* **🔢 Dynamic Counters:** Animated statistics section (e.g., 1500+ LinkedIn Network).
* **📱 Fully Responsive:** Carefully structured CSS Media Queries ensuring perfect display on mobile, tablet, and desktop screens.
